# INPUTS — Acknowledged Assumptions

Part VIII.3 of v93.1. These are assumptions, not results. Any new work that
uses them must state them as such wherever they enter. An input is never
promoted to a derivation by relabeling.

1. **Generation count.** Three generations of fermions is an input (§V.2
   verdict). State "three generations assumed" wherever fermion content is
   discussed. See `problems/IX2-modeling-decisions.md` §2.2.
2. **The value of $\bar\psi$.** The baseline tension is an initial datum under
   conserved dynamics; no mechanism sets it (§IX.5, problem 5.1). Any result
   conditional on $\bar\psi$ being in the $D_{4}$ band must say so.
3. **Tuning of $q_0$ onto the $D_{4}$ shell.** The ordered branch vanishes at
   detuning 0.5 in $q_0^2$ (§II.7). The 11.85% band figure is conditional on
   this tuning — cite the qualification every time the figure is cited.
4. **Conserved substrate dynamics.** Model B ($\partial_t\psi =
   \nabla^2(\delta F/\delta\psi)$) is a requirement, not a modeling choice:
   Model A drives $\bar\psi$ out of the stable band (§I.3).
5. **The dimensional assignment.** Readings (A)/(B)/(C) are mutually exclusive
   and undecided (§IX.2, problem 2.1). New work must declare which reading it
   assumes — or state that it is reading-independent and show why.
